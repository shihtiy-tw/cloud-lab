# cloud.init

## Purpose

Scaffold a new cloud service with standardized directory structure, Terraform files, and documentation.

## CSP Support

**Supported Clouds**: `aws`, `gcp`, `azure`, `oracle`

## Usage

```bash
# Initialize new AWS compute service
./scripts/cloud.init.sh --cloud aws --category compute --name fargate-cluster

# Initialize GCP storage service
./scripts/cloud.init.sh --cloud gcp --category storage --name gcs-bucket

# Initialize with specific template
./scripts/cloud.init.sh --cloud azure --category database --name cosmos --template serverless-db

# Initialize with scenarios
./scripts/cloud.init.sh --cloud aws --category networking --name transit-gateway --with-scenarios
```

## Parameters

- `--cloud` (required) - Cloud provider: `aws` | `gcp` | `azure` | `oracle`
- `--category` (required) - Service category: `compute` | `storage` | `database` | `networking` | `security` | `monitoring`
- `--name` (required) - Service name (kebab-case)
- `--template` (optional) - Base template to use
- `--with-scenarios` (optional) - Include scenarios directory
- `--with-tests` (optional) - Include test scaffolding (default: true)

## Prerequisites

- Cloud directory exists
- Templates available in `shared/templates/`

## Steps

1. Validate inputs
2. Check for naming conflicts
3. Create directory structure
4. Generate Terraform files
5. Create README.md
6. Initialize tests if requested
7. Add to documentation index

## Generated Structure

```
{cloud}/{category}/{name}/
├── infrastructure/
│   ├── main.tf
│   ├── variables.tf
│   ├── outputs.tf
│   ├── versions.tf
│   └── terraform.tfvars.example
├── scenarios/           # if --with-scenarios
│   └── basic/
│       ├── main.tf
│       └── README.md
├── tests/
│   ├── unit/
│   │   └── {name}_test.go
│   └── integration/
│       └── {name}_integration_test.go
├── utils/
│   └── .gitkeep
└── README.md
```

## CSP-Specific Defaults

### AWS
- Provider: `hashicorp/aws` >= 5.0
- Backend: S3 with DynamoDB
- Common patterns: IAM roles, security groups

### GCP
- Provider: `hashicorp/google` >= 5.0
- Backend: GCS
- Common patterns: Service accounts, firewall rules

### Azure
- Provider: `hashicorp/azurerm` >= 3.0
- Backend: Azure Blob
- Common patterns: Managed identities, NSGs

### Oracle
- Provider: `oracle/oci` >= 5.0
- Backend: OCI Object Storage
- Common patterns: Policies, security lists
